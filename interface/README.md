# Interface — La Bible du Foot

Ce dossier sert de référence pour tous les visuels remplaçables de l'application.

## Règles
- Format conseillé : PNG ou WebP.
- Rubriques d'accueil : ratio 16:9 ou 4:3, minimum 1200 px de large.
- Logo : PNG/WebP carré avec fond transparent si possible.
- Splash : portrait 9:16, minimum 1080x1920.
- Les noms de fichiers doivent rester exactement identiques à ceux listés dans `images-manifest.json`.
- Les futures images finales seront intégrées dans `app/src/main/res/drawable-nodpi/`.

## Rubriques
Accueil, Technique, Tactique, Défense, Milieu, Attaque, Gardien, Vitesse, Endurance, Explosivité, Préparation physique, Récupération, Prévention blessures, Séances individuelles, Séances collectives, Échauffements, Tests & progression, Créateur de séance, Favoris, Historique, Réglages/Mises à jour.
